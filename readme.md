## 5 Bit Carry Look Ahead Adder

A synchronous 5-bit Carry Look-Ahead (CLA) Adder, designed at the transistor level using 180nm CMOS technology, using TSPC D flip-flops. \
Executed schematic design, pre-layout SPICE simulation, and rigorous timing analysis in NGSpice to characterize critical metrics including setup/hold times, Clock-to-Q delay, and maximum operating frequency.}
Custom cell layouts were created in MAGIC EDA for individual logic gates and TSPC modules utilizing Euler path optimization to minimize silicon area, followed by Design Rule Checking (DRC) and Parasitic Extraction (PEX).}
The architectural correctness was validated by developing a behavioral Verilog RTL model, executing functional verification in Xilinx Vivado, and prototyping the design via FPGA implementation. \

Created as part of the course project in the course VLSI Design at IIIT Hyderabad.
